# 📚 DSA Daily

A repository documenting my journey of learning **Data Structures and Algorithms (DSA)** through consistent daily practice in **Java**.

## 🎯 Goal

Solve **at least three DSA problems every day**, strengthening my understanding of algorithms, data structures, and problem-solving while improving my Java skills.

## 📖 Topics

This repository will cover:

- Arrays
- ArrayLists
- Linked Lists
- Stacks
- Queues
- HashMaps
- Strings
- Recursion
- Trees
- Heaps
- Graphs
- Searching Algorithms
- Sorting Algorithms
- Dynamic Programming
- Greedy Algorithms
- Backtracking

## 🧪 Testing

Every solution is accompanied by unit tests to verify correctness and reinforce test-driven thinking.
